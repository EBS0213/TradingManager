# 로컬 초기 자료와 스크리너 예약

## 초기 자료

설치 시 DB 스키마 생성 후 `seed/screener`와 `seed/content`를 자동 등록합니다. 한국 스크리닝 2,771종목, 기업분석 PDF 75건, 컨퍼런스콜 49건을 포함합니다. 날짜는 원본 기준이며 실시간 자료가 아닙니다. 미국 전체 스크리닝 보관본은 확보하지 못했으므로 첫 수집 완료 전에는 미국 결과가 비어 있을 수 있습니다.

웹 DB 전체 복원은 아직 아닙니다. 기존 웹은 `DEPLOYMENT_DISABLED`, 연결된 프로젝트의 환경변수 조회는 접근 불가 상태여서 로컬 보관 자료를 사용했습니다. 완전한 DB 내보내기 자료를 확보하면 빠진 리포트·콜·미국 결과를 추가해야 합니다.

## 미국 가격 경로

- 종목 목록: Nasdaq Trader의 `nasdaqtraded.txt`.
- 가격: Yahoo Finance chart endpoint의 정규장 일별 OHLCV. 별도 유료 키 없음.
- `web/scripts/collect-us.mjs` → `data/us-bars`(완료 일봉), `data/us-live`(별도 정규장 관측값) → Python 스크리너 → 로컬 DB.
- 전일 캐시만 읽던 `us-cached` 실행을 실제 수집 `us`로 변경하고, 비활성화돼 있던 관측값 반영을 복원했습니다. 확정 일봉 파일에 미완성 봉을 섞지 않습니다.
- 같은 날 재수집은 기존 이력에 최근 5일을 합칩니다. 첫 수집/거래일 변경 시 장기 이력을 받습니다. 중단 후 재개 시 90분 이내 관측 캐시는 재사용합니다.
- 두 수집 작업만 병렬 실행하고 요청 사이에 간격을 둡니다. HTTP 401/403/429는 중단하고 다음 재시도까지 기다립니다. 전 종목 수집 기준을 충족하지 못하면 완전한 RS 순위인 것처럼 게시하지 않습니다.

## 예약 (한국시간)

- 한국: 기본 평일 16:00. `web/.env.local`의 `RUN_HOURS`(예: `"10,12,14,16"`)로 변경 가능.
- 미국: 월~금 저녁 22:30 시작, 다음 날 00:30·02:30·04:30·06:30·08:30. 금요일 밤 작업은 토요일 아침까지 이어집니다. 09:00에는 추가 작업을 시작하지 않습니다.
- 한국·미국을 독립 실행합니다. 성공한 슬롯은 `data/screener-schedule.json`에 보관하고 실패는 10분 이후 재시도합니다. 재개 시 최신 미처리 슬롯 하나를 실행하며 과거 슬롯을 전부 몰아서 돌리지 않습니다.
- 미국 일정은 KST 고정입니다. 미국 서머타임에 따라 22:30의 시장 개장 여부는 달라집니다. 정규장 밖에는 마지막 관측값이 유지되며 연장장 실시간 시세를 제공한다는 뜻은 아닙니다.
- 컴퓨터가 켜져 있고 인터넷이 연결돼 있어야 합니다. macOS는 설치된 사용자 서비스, Windows는 실행 창이 열려 있는 동안 동작합니다. 절전 중 정시에 실행하거나 공급자가 매번 응답하는 것을 보장하지 않습니다.
- 최초 미국 전 종목 이력 수집은 오래 걸릴 수 있습니다. 2시간은 실행 예정 간격이며, 이전 작업이 끝나지 않으면 같은 시장의 작업을 겹쳐 시작하지 않습니다.

진행 상태: `data/us-collection-status.json`, 실행 로그: `logs/com.tm26.local.screener.log`.
