TradingManager — Windows edition

1. Install Python 3.12, Node.js 22+, and PostgreSQL 17 or 18.
2. Extract the complete ZIP into a writable permanent folder.
3. Run Install-Windows.cmd (normal user; do not run from inside the ZIP).
4. Open the TradingManager desktop shortcut or Start-Windows.cmd.
5. Keep the launcher window open. Press Ctrl+C in that window to stop.

Personal records stay in data/postgres. Secrets stay in web/.env.local.
Never upload these folders/files when sharing the program.

The chatbot uses your local Ollama and model. No developer API keys are included.
Report shell automation is optional and requires WSL on Windows; the main app does not.

This is an installation-script/source bundle, not a self-contained EXE.
See README.md for Korean instructions and prerequisites.
