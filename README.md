# TradingManager

개인 컴퓨터에서 실행하는 투자 리서치·매매 기록 프로그램입니다. 설치한 이용자가 자기 프로그램의 관리자이며, 회원가입이나 로그인 없이 모든 화면을 사용합니다.

## 제공 기능

화면은 시장과 기업을 조사하는 **터미널**, 종목을 선별하고 매매를 복기하는 **트레이딩**으로 나뉩니다. 개인 기록과 설정은 설치한 컴퓨터에 저장합니다. 시장 자료 조회와 선택적 외부 서비스에는 인터넷 연결이 필요합니다.

| 기능 | 할 수 있는 일 |
| --- | --- |
| 시장 대시보드 | 주요 글로벌 지수와 주요 주식의 현재값·등락률을 확인하고 시장 흐름을 살펴봅니다. 제공처 조회 실패 시 지원 지수의 보완 데이터를 사용합니다. |
| 주식·ETF 분석 | 종목을 검색하고 시세·차트·기업 분석 자료를 확인합니다. ETF와 섹터 ETF를 별도 화면에서 살펴볼 수 있습니다. |
| 경제 데이터·국가 비교 | 경제 지표와 국가별 자료를 조회하고 국가 간 흐름을 비교합니다. 데이터 소스 화면에서 제공처와 수집 상태를 확인합니다. |
| 뉴스 | 시장·기업 관련 뉴스를 모아 리서치에 활용합니다. |
| 한국·미국 스크리닝 | 종목별 규칙과 점수를 기반으로 후보를 검토하고, 셋업과 라이언 가이드를 참고해 분석을 이어갑니다. 수집 작업은 수동 또는 예약 실행 구조를 사용합니다. |
| 포트폴리오·관심종목 | 보유자산과 관심 자산을 관리하고, 종목 조사와 개인 기록을 연결합니다. |
| 매매일지 | 매매 내역, 전략, 심리와 메모를 저장해 자신의 판단을 복기합니다. 브라우저와 macOS 앱은 같은 로컬 프로필을 사용합니다. |
| 차트게임 | 포함된 과거 시세로 차트 판단을 연습하고 진행 상황·완료 기록·점수를 저장합니다. |
| 리서치·컨퍼런스콜 | 저장한 보고서와 첨부 자료를 열람하고 컨퍼런스콜 자료를 확인합니다. 별도 일반 게시판 메뉴는 제거했으며 리서치 저장 기능은 유지합니다. |
| 항공·해상·운임 | 별도 수집기를 통해 항공·해상 관측 및 운임 자료를 표시합니다. 공급자 연결 상태와 갱신 시각에 따라 제공 범위가 달라지며 일부 공급자는 별도 키 설정이 필요합니다. |
| 로컬 AI 챗봇 | 자신의 컴퓨터에서 실행하는 Ollama 모델과 대화하고 대화 기록을 보관합니다. Ollama와 모델은 별도로 준비해야 합니다. |
| 보고서 자동화 | 자료 수집, 보고서 작성·검토, 첨부와 로컬 등록 도구를 제공합니다. 외부 AI·채널 발송·예약 작업은 사용자가 해당 서비스와 실행 환경을 별도로 설정합니다. |

이 프로그램의 중심은 리서치·기록·연습입니다. 시세 갱신 주기와 데이터 범위는 공급자에 따라 달라지며, 모든 자료가 실시간으로 제공되는 것은 아닙니다. 새 설치에는 개인 보고서·매매 기록·AI 대화가 들어 있지 않습니다.

## 최신 업데이트 — 2026-11-08

- **설치 간소화:** macOS 커맨드 파일에서 필수 도구 확인·준비를 시작합니다. 실패 후 재실행하면 기존 설정·DB를 보존하고 완료한 설치 단계를 재사용합니다.
- **실행 오류 개선:** 신규 설치의 포트 충돌을 피하고 앱·수집기·챗봇·보고서 모듈이 동일한 로컬 주소를 사용합니다. 사용자 서비스 접근 실패를 설치 전에 확인하고 중단 원인을 로그로 남깁니다.
- **백엔드 효율 개선:** DB 최초 연결과 종목 목록 다운로드의 동시 요청을 합치고, 캐시 파일 동시 저장 충돌을 해결했습니다.
- **화면 정리:** 일반 게시판을 제거하고 기존 링크를 리서치로 연결합니다. 뉴스 등에서 불필요하게 경제 데이터를 요청하던 동작도 줄였습니다.
- **검증 확대:** 웹·설치기·챗봇·수집기·보고서 자동화 테스트 총 334개와 웹·Mac 앱 빌드를 로컬에서 통과했습니다. 새 Mac 전체 설치와 Windows 실기기 검증은 별도 과제로 남아 있습니다.

변경 이유와 검증 범위는 [변경 기록](CHANGELOG.md), [코드 검토 결과](docs/audit.md), [구조 설명](docs/architecture.md)에서 확인할 수 있습니다.

**이번 개선은 저장소의 `main` 소스 기준입니다.** [현재 소스 ZIP](https://github.com/EBS0213/TradingManager/archive/refs/heads/main.zip)을 받거나 `git clone https://github.com/EBS0213/TradingManager.git`으로 내려받으세요. [GitHub Releases](https://github.com/EBS0213/TradingManager/releases)의 기존 v1.1.1 압축파일은 이번 변경을 포함하지 않습니다.

## 운영체제별 설치

| 배포 | 설치 | 실행 |
| --- | --- | --- |
| macOS (Apple Silicon) | `Install-macOS.command` 또는 `설치.command` | 바탕화면 `TradingManager.app` |
| Windows 10/11 x64 | `Install-Windows.cmd` | 바탕화면 `TradingManager` 또는 `Start-Windows.cmd` |

두 버전은 같은 웹·개인 기록·차트게임·Ollama AI 코드를 사용합니다. Windows판은 기본 브라우저에서 열리고, macOS판은 전용 앱 창에서 열립니다. 배포 파일에 실행 시 생성되는 데이터와 키는 넣지 않습니다.

### Windows 설치

1. [Python 3.12](https://www.python.org/downloads/windows/), [Node.js 22 이상](https://nodejs.org/en/download), [PostgreSQL 17 또는 18](https://www.postgresql.org/download/windows/)을 설치합니다. Python 설치 시 PATH 추가를 선택하세요. 이미 준비돼 있으면 건너뜁니다.
2. Windows ZIP을 **완전히 압축 해제**해 쓰기 가능한 고정 폴더에 둡니다. `Program Files`와 OneDrive 동기화 폴더는 피하세요.
3. `Install-Windows.cmd`를 실행합니다. 관리자 권한은 필요하지 않습니다. 의존성 다운로드를 위한 인터넷 연결이 필요합니다.
4. 바탕화면의 `TradingManager` 또는 `Start-Windows.cmd`로 시작합니다. 실행 창은 열어 두고 종료할 때 `Ctrl+C`를 누르세요. 브라우저 탭만 닫으면 프로그램은 계속 실행됩니다.

Windows 설치기는 별도 PostgreSQL 클러스터를 `data/postgres`에 만듭니다. 기존 PostgreSQL 서비스의 DB를 사용하거나 초기화하지 않습니다. 중간 실패 후 설치 파일을 다시 실행하면 기존 키와 DB를 유지하고 설치를 이어갑니다. 설치 폴더는 설치 후 이동하지 마세요. 다른 위치에 PostgreSQL을 설치했다면 `TRADINGMANAGER_PG_BIN`에 해당 `bin` 경로를 지정하세요.

확인만 하려면 `py -3 desktop/windows.py install --check`를 실행합니다.

### macOS 설치

Apple Silicon Mac에서는 압축을 완전히 해제한 뒤 `Install-macOS.command`(또는 `설치.command`)를 더블클릭합니다. 설치 파일이 Homebrew·Node.js·Python·PostgreSQL 18·Apple 개발 도구를 확인하고 필요한 준비를 이어서 안내합니다. 처음 Homebrew나 Apple 개발 도구를 설치할 때 운영체제 승인 또는 암호 입력이 필요할 수 있습니다. 공식 Homebrew 설치 절차: https://docs.brew.sh/Installation

저장소를 내려받은 폴더에서 커맨드 파일을 실행하세요. 터미널에서는 `bash desktop/bootstrap-macos.sh`로 같은 준비 절차를 시작할 수 있습니다. 필수 도구가 이미 준비된 개발 환경에서는 다음 명령을 사용합니다.

```sh
python3 desktop/setup.py --check
python3 desktop/setup.py
```

설치는 이용자 전용 DB와 무작위 로컬 키를 만들고, 웹을 빌드해 바탕화면에 `TradingManager.app`을 설치합니다. 기본 웹 포트 `8766`이나 DB 포트가 사용 중이면 신규 설치가 다른 빈 포트를 선택합니다. 실제 주소는 `web/.env.local`의 `TM26_URL`에 저장되고 앱·챗봇·수집기·보고서 모듈이 함께 사용합니다. 다른 프로그램을 종료하지 않습니다.

실패하면 같은 커맨드 파일을 다시 실행하세요. 기존 키·기록·DB는 유지하고 완료된 의존성/빌드 단계는 재사용합니다. 설치 로그는 `logs/install.log`입니다. 불완전한 기존 DB나 다른 설치의 서비스를 발견하면 자동 삭제하지 않고 이유를 표시합니다. 파일은 설치 후 고정된 위치에 두세요. 프로그램은 이 컴퓨터에서만 접속할 수 있습니다.

## 기록과 차트게임

트레이딩 → 기록에서 매매·보유자산·전략·심리를 저장합니다. 관심종목, 완료한 차트게임과 진행 중인 게임, AI 대화 기록은 로컬 PostgreSQL에 보관합니다. 브라우저와 맥 앱은 같은 로컬 프로필을 사용합니다. 차트게임용 과거 시세와 문제 데이터는 `web/public/training/data`에 포함됩니다.

실제 개인 데이터는 `data/`, 비밀 설정은 `web/.env.local`에 있습니다. 이 파일들은 GitHub와 배포 ZIP에 포함하지 않습니다. 컴퓨터를 옮길 때 개인 데이터 백업은 소스 다운로드와 별도로 수행해야 합니다.

## AI 챗봇과 비용

기본 챗봇은 **설치자 컴퓨터의 Ollama**(`127.0.0.1:11434`)를 사용합니다. Ollama에 사용할 모델을 설치한 뒤 해당 모델 이름을 지정해 실행합니다.

```sh
TM26_CHAT_MODEL=설치한_모델명 python3 workers/chat/chat_worker.py
```

macOS의 스크리너와 챗봇은 로컬 서비스로 등록됩니다. Windows에서는 실행 창이 두 워커를 함께 시작·종료합니다. 모델을 바꾸려면 실행 중인 챗봇 서비스를 중지하고 위 명령으로 실행하세요.

Windows에서 모델을 지정하려면 PowerShell에서 `$env:TM26_CHAT_MODEL="설치한_모델명"`을 설정한 뒤 `.\Start-Windows.cmd`를 실행하세요.

챗봇 워커는 설치 시 생성한 전용 토큰으로 같은 컴퓨터의 웹에만 연결됩니다. 배포자의 API 키, 로그인 세션, 토큰, DB는 제공하지 않습니다. 모델이 준비되지 않으면 챗봇은 오프라인으로 표시합니다.

선택적 외부 AI 기능은 이용자가 `web/.env.local`에 **자신의** `ANTHROPIC_API_KEY`를 입력하고 `TM26_PAID_AI_ENABLED="1"`로 설정해야 활성화됩니다. 기본값은 `0`입니다. 외부 API 요금은 이용자가 입력한 키의 계정에 발생합니다. 보고서 자동화에서 외부 AI를 사용할 때도 이용자 자신의 설정이 필요합니다.

## 보고서 자동화

보고서 소스는 두 배포본에 함께 있습니다. macOS에서는 기존 셸·예약 도구를 사용합니다. Windows의 **보고서 제작/예약 셸 자동화는 WSL 환경이 추가로 필요**하며 Windows 네이티브 설치기가 이를 자동 설치하지 않습니다. 기본 웹·개인 기록·차트게임·Ollama 챗봇에는 WSL이 필요하지 않습니다. 자세한 설정과 본인 AI 로그인은 `report-automation/README.md`를 확인하세요.

## 개발과 검증

```sh
cd web
npm ci
npm run build
npm test
node --env-file=.env.local tests/local-records-smoke.cjs
```

브라우저 검증은 Chrome과 로컬 PostgreSQL을 사용합니다. `TEST_CHROME_PATH`로 다른 Chrome 경로를 지정할 수 있습니다. GitHub Actions의 Desktop installers 워크플로는 Windows 새 설치·시작/종료·재시작·브라우저 저장과 macOS 빌드/앱 제작을 검증합니다. 별도 임시 스키마에서 저장·재접속·차트게임·대화 기록을 검증하고 삭제하며, 실제 개인 기록은 변경하지 않습니다.

라이선스 및 외부 구성요소 고지는 `LICENSE`와 `web/THIRD_PARTY_NOTICES.md`를 확인하세요. 시장 데이터의 제공 조건은 해당 공급자에게 적용됩니다.
