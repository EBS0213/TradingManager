# 기본 리서치 자료

기업분석 PDF 75건과 컨퍼런스콜 게시 자료 49건을 로컬 보관본에서 복원한 묶음입니다. 웹 서비스가 중단돼 있어 웹 DB 전체와의 일치 여부는 확인하지 못했습니다. `manifest.json`의 `completeCloudExport: false`가 이 범위를 나타냅니다.

설치기의 `init-db.mjs`가 체크섬을 확인하고 로컬 PostgreSQL에 등록합니다. 원래 문서 날짜는 파일명과 컨퍼런스콜 payload에 유지합니다. 계정·비밀번호·개인 매매 기록·관심종목은 포함하지 않습니다. PDF와 컨퍼런스콜 원문/번역은 작성 당시 자료이며 현재 시세가 아닙니다.

재실행은 적용 이력을 확인합니다. 기존 자료와 같은 첨부 또는 같은 종목·분기는 덮어쓰지 않습니다. 사용자가 삭제한 초기 보고서도 재설치로 되살리지 않습니다. 새 설치에서는 인터넷에서 과거 사이트를 호출하지 않아도 조회할 수 있습니다.

유지보수 도구: `python3 tools/package_content_seed.py <승인된_보관본_디렉터리>`.
