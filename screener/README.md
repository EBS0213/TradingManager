# 미너비니 SEPA 스크리너

코스피 · 코스닥 전 종목을 **2시간마다** 자동으로 훑어서, 미너비니의 Trend Template
8개 조건을 전부 통과한 종목만 뽑아 보여줍니다.
엑셀 워크북 `종목스크리닝` 시트와 판정 방식이 **완전히 같습니다**.

---

## 1. 설치 (한 번만)

1. 이 폴더를 통째로 원하는 곳에 둡니다. (예: `~/Documents/미너비니스크리너`)
2. **`설치하기.command` 를 더블클릭**합니다.
3. "확인되지 않은 개발자" 경고가 뜨면
   → 파일을 **마우스 우클릭 → 열기 → 열기** 를 누르면 실행됩니다.
   → 또는 `시스템 설정 → 개인정보 보호 및 보안` 맨 아래 **"확인 없이 열기"**
4. 창에 `설치가 끝났습니다` 가 나오면 끝입니다.

설치 창이 하는 일은 네 가지입니다.
파이썬 확인 → 라이브러리 설치 → 가짜 데이터로 동작 확인 → 2시간마다 자동 실행 등록.

> 파이썬이 없다고 나오면 <https://www.python.org/downloads/> 에서 받아 설치한 뒤
> 다시 더블클릭하세요.

## 2. 쓰는 법

| 하고 싶은 것 | 방법 |
|---|---|
| **결과 보기** | **`대시보드 열기.command`** 더블클릭 (파일 올릴 필요 없음) |
| 지금 바로 다시 돌리기 | **`지금 실행.command`** 더블클릭 → 끝나면 대시보드가 열림 |
| 데이터가 안 받아질 때 | **`진단.command`** 더블클릭 → 나온 내용을 알려주기 |
| 웹사이트에 올리기 | **`웹배포 만들기.command`** → `web/` 폴더를 업로드 |
| 통과 종목만 짧게 보기 | `output/summary.txt` |
| 엑셀로 옮기기 | `output/result.csv` |
| **관심종목 담기** | 대시보드 표의 ☆ → 워치리스트 탭 → **[맥에 바로 저장]** |
| 기준값 바꾸기 | `config.yaml` 을 메모장으로 열어 숫자 수정 |
| 자동 실행 끄기 | **`자동실행 끄기.command`** 더블클릭 |

**첫 실행은 10~25분 걸립니다.** 종목별로 1년 반치 주가를 받아 `data/` 폴더에
저장하기 때문입니다. 두 번째부터는 최근 며칠치만 받으므로 **3~6분**이면 끝납니다.

> **업종 분류 기준**
> 업종은 **한국거래소 KIND 상장법인목록**에서 가져옵니다. 통계청 **한국표준산업분류(KSIC)**
> 기반의 공식 분류라 벤치마크로 쓰기에 적합하고, '주요제품'도 함께 받아 업종 칸에
> 마우스를 올리면 보여 줍니다. `config.yaml` 의 `sector_source` 로 바꿀 수 있습니다
> (`krx` 권장 / `naver` / `both`).

> **데이터 출처 안내 (2026년 변경)**
> KRX(한국거래소)가 2026년부터 로그인 없이는 데이터를 주지 않도록 바뀌었습니다.
> 그래서 이 프로그램은 **네이버 금융**에서 주가·업종·실적을 받습니다. 별도 가입이 필요 없습니다.
> KRX 계정이 있다면 터미널에서 `export KRX_ID=아이디`, `export KRX_PW=비밀번호` 를
> 설정한 뒤 실행하면 KRX 쪽을 씁니다(더 빠릅니다).

자동 실행은 맥이 켜져 있을 때만 돕니다. 잠자기 중이면 깨어난 직후에 한 번 돕니다.

## 3. 대시보드 보는 법

**위쪽 숫자 카드**

- **8조건 전부 통과** — 매수 후보. 이 숫자가 0이면 미너비니 기준으로는 **쉬어야 할 시장**입니다.
- **시장 온도** — 전체 중 통과 종목 비율. 5% 아래면 약세장, 15% 위면 강세장 신호로 씁니다.
- **새로 통과** — 직전 실행에는 없다가 이번에 올라온 종목. 여기부터 보면 됩니다.

**표의 각 열**

| 열 | 뜻 | 좋은 값 |
|---|---|---|
| RS | 시장 전체 대비 상대강도 순위 (1~99) | 80 이상이면 주도주 |
| 저점대비 | 52주 최저가 대비 상승률 | +30% 이상 (조건 ⑥) |
| 고점대비 | 52주 최고가 대비 현재 위치 | -25% 이내 (조건 ⑦) |
| **피벗가격** | 최근 8주 고점 = 매수 버튼 누를 가격 | 여기를 거래량과 함께 뚫을 때 |
| **피벗대비** | 현재가가 피벗에서 얼마나 떨어져 있나 | **+2% 이내**. 넘으면 추격 매수 |
| **손절가 제안** | 베이스 저점 아래 / 피벗 -8% 중 높은 쪽 | 손절폭 5~6%면 이상적 |
| 수축 | 변동폭이 줄고 있는지 (참고값) | '수축' 표시면 우선 확인 |
| 거래량비 | 최근 5일 ÷ 베이스 평균 거래량 | 1.0 미만 = 매물 마름 |
| **매집** | 상승일 거래량 vs 하락일 거래량 (미너비니식) | 매집 |
| **수급** | 외국인·기관 20일 누적 순매수 (한국 전용) | 쌍끌이 |
| 실적 | EPS 20%↑ · 매출 15%↑ 충족 여부 | 충족 |
| 8개 조건 | O/X 여덟 칸. 칸에 마우스를 올리면 조건 이름이 뜹니다 | 전부 O |

종목명·업종은 검색창으로 걸러지고, 표의 **제목을 클릭하면 그 기준으로 정렬**됩니다.

## 3-1. 미너비니 8개 조건

대시보드 위쪽 **"미너비니 8개 조건이 정확히 무엇인가"** 를 누르면 조건별 설명과
이번 스크리닝에서 각 조건을 통과한 종목 수가 표로 나옵니다.

| # | 조건 | 무엇을 보나 |
|---|---|---|
| ① | 현재가 > 150일선 & 200일선 | 중기·장기 평균 위 = 위에서 쏟아질 매물이 적음 |
| ② | 150일선 > 200일선 | 최근 흐름이 예전보다 강해짐 |
| ③ | 200일선 상승 중 (20거래일 전 대비) | 장기 추세 자체가 위 — 하락장 종목을 걸러내는 핵심 |
| ④ | 50일선 > 150일선 & 200일선 | 50 > 150 > 200 정배열 = 2단계 상승 추세 |
| ⑤ | 현재가 > 50일선 | 지금 이 순간에도 힘이 살아 있음 |
| ⑥ | 52주 최저가 대비 **+30% 이상** | 바닥에서 확실히 올라온 종목만 |
| ⑦ | 52주 최고가 대비 **-25% 이내** | 고점에서 너무 밀리지 않았을 것 |
| ⑧ | RS 순위 **70 이상** | 시장 상위 30% 안의 상대강도 |

**하나라도 X면 후보에서 뺍니다.** 조건을 느슨하게 푸는 순간 이 방법론은 작동하지 않습니다.

## 3-0. 결과를 보는 세 가지 방법

| 방법 | 파일 올리기 | 워치리스트 저장 | 언제 쓰나 |
|---|---|---|---|
| **`대시보드 열기.command`** (권장) | 필요 없음 | **버튼 한 번에 맥에 저장** | 평소 |
| `output/dashboard.html` 더블클릭 | 필요 없음 | 내려받기 → 수동 이동 | 서버 켜기 귀찮을 때 |
| 웹 (`web/` 업로드) | 필요 없음 (result.csv 자동 읽음) | 내려받기 → 재업로드 | 밖에서 폰으로 볼 때 |

**`대시보드 열기.command`** 는 맥 안에서만 도는 작은 서버(127.0.0.1)를 띄웁니다.
바깥에서는 접속할 수 없고, 창을 닫으면 꺼집니다. 이 방식으로 열면 화면 오른쪽 위에
`● 연결됨` 이 뜨고, 워치리스트에 **[맥에 바로 저장]** 버튼이 생깁니다.

`output/dashboard.html` 은 **결과 데이터가 파일 안에 통째로 박혀 있어서**
그냥 더블클릭해도 바로 보입니다. 2시간마다 새로 만들어지므로 항상 최신입니다.

## 3-2. 관심종목 (Watchlist)

`output/watchlist.csv` 에 적어 둔 종목은 매 실행마다 따라가며 **지금 몇 개 조건을
통과 중인지** 대시보드 위쪽에 따로 보여줍니다.

```
코드,종목명,메모,추가일
005930,삼성전자,50일선만 회복하면 진입,2026-08-09
```

**7개만 통과한 종목을 여기 담아 두세요.** 마지막 한 개가 채워지는 순간 `8/8 통과` 로
바뀌고 `summary.txt` 에도 표시됩니다. 8조건 통과를 매번 눈으로 찾을 필요가 없어집니다.

가장 편한 방법은 **`대시보드 열기.command`** 로 연 뒤 표의 **☆** 를 누르고
워치리스트 탭에서 **[맥에 바로 저장]** 을 누르는 것입니다. 파일을 옮길 필요가 없습니다.

## 4. 이 프로그램이 하지 않는 것

솔직하게 적어 둡니다.

- **매수 신호가 아닙니다.** 8조건은 "볼 만한 종목"을 2,700개에서 수십 개로 줄이는
  필터일 뿐입니다. 실제 진입은 차트에서 VCP와 피벗을 눈으로 확인한 뒤 결정하세요.
- **VCP 자동 판정은 참고용입니다.** 수축 구조는 사람이 차트로 봐야 정확합니다.
  이 프로그램의 '수축' 열은 "먼저 볼 순서"를 정해 주는 정도로만 쓰세요.
- **실적 데이터는 무료로 긁어온 것**이라 종목에 따라 비어 있을 수 있습니다.
  그런 종목은 `실적?` 으로 표시하고 탈락시키지 않습니다
  (`config.yaml` 의 `pass_when_unknown` 으로 바꿀 수 있습니다).
- **장중 값은 잠정치**입니다. 확정 판단은 종가 기준(15:40 이후 실행분)으로 하세요.

## 5. 문제가 생기면

| 증상 | 해결 |
|---|---|
| **`대상 0종목` / 주가를 하나도 못 받음** | **`진단.command`** 를 돌려서 어디서 막히는지 확인 |
| 라이브러리 오류 | 터미널에서 `cd` 로 이 폴더에 간 뒤 `pip3 install -r requirements.txt` |
| 중간에 실패가 많음 | `config.yaml` 의 `max_workers` 를 6으로 낮추고 `request_delay` 를 0.3으로 올리기 |
| 결과가 계속 0종목 | 정상일 수 있습니다. 약세장에서는 통과 종목이 0인 게 맞습니다 |
| 자동 실행이 안 됨 | `자동실행 끄기.command` → `설치하기.command` 순서로 다시 실행 |
| 처음부터 다시 받고 싶음 | `data/ohlcv.parquet` 파일을 지우고 다시 실행 |

로그는 `logs/` 폴더에 월별로 쌓입니다. 오류 메시지를 그대로 복사해서 물어보시면 됩니다.

## 6. 폴더 구조

```
minervini-screener/
├── 설치하기.command        ← 처음 한 번 더블클릭

├── 진단.command            ← 데이터가 안 받아질 때

├── 자동실행 끄기.command
├── config.yaml             ← 기준값 조정
├── run.py                  ← 실행 진입점
├── screener/
│   ├── config.py           설정 읽기
│   ├── sources.py          데이터 공급원 (네이버 / KRX)
│   ├── data.py             주가·업종 수집 및 캐시
│   ├── rules.py            8조건 + RS 계산  ★핵심
│   ├── fundamentals.py     EPS·매출 확인
│   ├── supply.py           외국인·기관 수급 (한국 전용)
│   ├── watchlist.py        관심종목 추적
│   └── report.py           대시보드·요약 생성
├── data/                   주가 캐시 (자동 생성)
├── output/                 결과물 (자동 생성)

│   ├── result.csv          전 종목 판정 결과
│   ├── summary.txt         통과 종목 요약
│   └── watchlist.csv       ← 관심종목을 여기에 적으세요
├── web/                    웹 업로드용 (자동 생성)
└── logs/                   실행 기록
```

데이터 출처: 주가·실적·수급 = 네이버 금융 · 업종 = 한국거래소 KIND(표준산업분류).
