# TradingManager 보고서 모듈

- 한국어 코드와 기존 작성·게시 흐름을 유지한다. 공개 배포 모듈이므로 개인 기록·실제 키·인계·생성 보고서를 커밋하지 않는다.
- 기업 리포트 작성에는 `skills/기업분석리포트/references/KIRS_리서치작성기준.md`를 적용한다. 사실·회사 계획·추정을 구분하고 근거와 기준일을 확인한다.
- 완성 후 자체 점검 → 게시대기 인계 → 상위 게시기로 즉시 게시한다. 별도 최종 승인 프롬프트나 자동 수정 왕복을 추가하지 않는다.
- 모델은 작성과 인계만 수행한다. 게시·첨부·발송은 기존 상위 코드가 담당하며 같은 실패 입력을 무한 반복하지 않는다.
- 이 설치 사용자의 로그인·키만 사용한다. 다른 사용자의 인증정보나 배포자의 서비스에 연결하지 않는다.
- Python 검증에는 이 폴더 `.venv`를 사용한다. 기본 점검은 AST 파싱·셸 문법·오프라인 테스트로 수행한다.
