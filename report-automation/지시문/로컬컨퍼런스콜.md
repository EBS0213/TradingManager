# 로컬 컨퍼런스콜 수집·작성 인계

이 문서는 로컬 자동화의 컨콜 작업 전용이다. 과거 요약형 게시 지시 대신 현재 전문·번역·정리본 형식을 사용한다. `AGENTS.md`, `지시문/_공통_문체기준.md`를 읽는다. 상위 실행기가 게시하므로 직접 게시·메시지 발송·예약 수정은 하지 않는다.

1. `SEC_USER_AGENT`, `SITE_URL`, `TM26_REPORT_PROVIDER`의 **설정 여부**만 확인한다. 키·로그인 파일·개인 설정을 답변이나 산출물에 복사하지 않는다. 문서에 적힌 고정 포트 대신 `SITE_URL`을 사용한다.
2. `python 컨퍼런스감시.py --새것 --날수 7`로 최근 공시 대기열을 확인한다. `캐시/미국시총상위.json`이 없으면 상위 실행기의 수집 로그를 확인한다. 없는 시총 순위를 임의로 만들지 않는다. 로컬 `/api/calls?view=index`에 있는 종목·회계분기는 다시 만들지 않는다. 이번 실행은 최대 5건이다.
3. 회사·티커·회계연도·분기를 확인한 공개 Motley Fool 컨퍼런스콜 원문을 수집한다. 유료벽·접근 차단을 우회하지 않는다. 원문이나 필수 설정이 없으면 해당 건은 수집 대기로 남기며, 자료를 지어내거나 실적 보도자료를 컨콜 전문이라고 표시하지 않는다. 동작하지 않는 이전 FMP 키 입력 창을 띄우지 않는다.
4. HTML에서 발표 본문과 Q&A를 추출한다. 뉴스·광고·네비게이션을 제거하고 문단을 빈 줄로 구분한다. 한국어 전문은 원문과 **같은 문단 수**로 번역한다. 완성된 번역과 요약만 게시대기 상태로 둔다. 중간 결과는 `캐시/로컬컨콜/`에 보존해 이어서 처리한다.
5. `브리핑/YYYY-MM-DD/컨퍼런스콜_YYYY-MM-DD.json`에 `{ "items": [...] }` 형식으로 쓴다. 각 item은 아래 필드를 포함한다. 세부 검증 기준은 `../web/lib/terminal/call-documents.mjs`와 `../web/app/api/calls/route.js`를 읽어 맞춘다.
   - `code`, `name`, `market: "해외"`, `quarter: "YYYY 회계연도 N분기"`, `date: "YYYY-MM-DD"`, `sector`, `headline`.
   - `summary` (6000자 이하), `call` (14000자 이하: 발표·가이던스·Q&A 분석), `industry`, `outlook` (각 4000자 이하), `numbers`, `sources`.
   - `documents`: `version:1`, `code`, `year`, `quarter`(숫자), `sourceUrl`, `title`, `original`(실제 영문 전문), `sha256`(original UTF-8 SHA-256).
   - `documents.translation`: `language:"ko"`, `paragraphs`(빈 줄로 나눈 원문 문단과 같은 개수), `sourceSha256`, `model`, `generatedAt`(ISO 시각). `model`은 실제 실행 도구에 따라 `Codex · 자동화` 또는 `Claude Code · 자동화`로 기록하며 다른 도구의 이름을 쓰지 않는다.
   - `pipeline`: `id:"local-transcript-v1"`, `collectedAt`(실제 수집 ISO 시각).
   - `transcriptSource`: `url`, `year`, `quarter`, `collector:"local-public"`, `sha256`. 사용하지 않은 수집 라이브러리의 버전·커밋을 적지 않는다.
6. 원문 종목·기간, 문단 수, SHA-256, 숫자와 출처를 자체 확인한다. 상위 게시기 `컨퍼런스콜게시.py`와 `자동검토.py`의 인계 형식을 읽고 `협업/검토대기/컨퍼런스콜_YYYY-MM-DD.md`에 `상태: 게시대기`와 위 JSON 자료 경로, 자체 점검 결과를 기록한다. 게시 완료로 표시하거나 대기열을 처리 완료로 지우지 않는다. 게시 후 검증·영수증은 상위 게시기가 담당한다.

새로운 자료가 없으면 `새 컨퍼런스콜 없음`과 조회 범위를 남긴다. 접근 차단·키 누락은 실패 원인으로 남긴다. 결과 없는 실행을 게시완료로 표현하지 않는다.
