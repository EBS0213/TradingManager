## 기록 자체가 틀렸을 때 — 오타와 실제 판단을 구분한다

로그의 숫자가 **명백히 오타**로 보이면 그것을 위반으로 세지 마십시오. 사람의 손이 미끄러진 것과
규칙을 어긴 것은 다릅니다. 아래를 오타로 봅니다.

· **손절가 = 매수가** 이거나 손절가가 매수가보다 **높은** 매수 건 → 자릿수·소수점 실수
    예) SMTC 매수가 143.1 · 손절가 143  → -0.07%. 이것은 "손절을 안 걸었다"가 아니라 **131.65 를 잘못 적은 것**
· 손절률이 **-30% 를 넘는** 값 → 옛 종목의 손절가를 그대로 둔 것으로 봅니다
· 손익률이 매수가·매도가와 맞지 않는 값

**처리 방법**
1. 「기록 오류」 표에 따로 적습니다 — 어느 행이, 어떻게 적혀 있고, 무엇이 맞는 값으로 보이는지
2. 규격 검사에서는 **제외**하고, 분모에서도 뺍니다. 분모를 밝히십시오
   («손절가 규격 준수 3/5 · 기록 오류 2건 제외»)
3. 다만 **「기록 품질」 점수는 깎습니다.** 오타도 기록의 문제이고, 오타 때문에 자동 손절이
   엉뚱한 값으로 걸려 있었다면 그것은 실제 위험입니다. 그 점을 한 줄로 짚으십시오

### PDF 에 담을 표 여섯 가지 (예전 엑셀 시트와 같은 내용)

1) **오늘** — 대상일·아침 계획 불러오기 성공 여부·한 줄 평·오늘의 숫자

   **누적 지표는 넣지 마십시오.** 누적 총점 기록표만 한 줄 추가합니다(추이를 잃지 않기 위해).

2) **계획 대비 실행** — **이 평가의 본체입니다.** 아래 「계획 대비 실행 시트 상세」를 그대로 따릅니다.

3) **오늘 거래** — 당일 체결 행 전부. 열: 시각 / 종목 / 매매구분 / 가격 / 수량 / 손익 / 손익률 / R배수 /
   스탑체결 / 권한사용 / 감정 / 규칙 준수(자가·보정) / 기록 원문 인용.
   행마다 **판정 한 줄**(정상·위반·확인 필요)과 그 근거를 답니다.

4) **그 거래의 뿌리** — ②. 오늘 청산된 건마다 한 덩어리씩.
   · 언제 · 얼마에 · 왜 샀는가 (진입 근거 원문 인용)
   · 그때 손절가를 어떻게 적었는가, 어느 기준으로 적었는가
   · 관찰일수 · 리서치 여부 · 권한 사용 여부
   · **그 결정 중 무엇이 오늘 결과를 만들었는가** — 이 한 줄이 이 시트의 이유입니다
   · 청산이 없는 날은 「오늘 청산이 없어 되짚을 진입이 없습니다」 한 줄

5) **오늘의 판정** — 규칙 위반 / 손 매도 / 조항 집행, 셋만 봅니다.
   · 아침 규칙 3개 각각 O · X · 해당 없음
   · 손 매도 판정은 ★(2) 세 조건으로
   · 그날 발동된 조항이 있으면 집행됐는가
   · **위반 0건이면 「오늘 매매로 인한 규칙 위반은 0건입니다」라고 크게 적습니다**

6) **채점 · 내일 지킬 것** — 6항목 각 1~10점 + 근거. **시험되지 않은 항목은 「해당 없음」으로 두고 평균에서 뺍니다.**
   총점은 AVERAGE 수식 + 가감. 아래에 누적 점수 기록표(오늘 행 추가)와 **내일 지킬 규칙 3개**.

**시트 7~10(유형별 성적·반복 패턴·문제 추적·솔루션)은 만들지 마십시오.** 주간평가로 옮겼습니다.
그날 눈에 띈 것이 있으면 6번 시트 맨 아래 **「주간평가로 넘길 것」** 표에 한 줄로 적어 두십시오.

글꼴 '맑은 고딕' 10pt. 회색(EDEDED)=자동 계산, 노란색(FFF2CC)=입력, 연빨강(FCE4E4)=문제, 연초록(E2EFDA)=잘한 점.
숫자는 하드코딩하지 말고 '오늘 거래' 시트를 참조하는 수식으로. XLOOKUP·FILTER·UNIQUE 금지.
**글자 잘림 방지**: 한글·전각 2·그 외 1로 폭을 세어 `줄수 = ceil(폭 / (열너비 - 3))`, `행높이 = 줄수 * 15 + 7` 로 직접 지정.

### PDF `브리핑/<대상일>/매매평가_<대상일>.pdf` — A4 2~4쪽

시트를 그대로 옮기지 말고 **문장으로 풀어 쓴 보고서**로. HTML 을 만들어 playwright chromium 으로 A4 인쇄.
폰트 'Noto Sans CJK KR' 10pt, 줄간격 1.6. `tr { page-break-inside: avoid; }` 를 넣고
**`page-break-before: always` 를 섹션마다 넣지 마십시오**(반쯤 빈 페이지가 생깁니다).

구성 — 요약 상자(총점 / 계획 일치율 / 실현손익 / 오늘 위반 건수 + 한 줄 평) →
1. 오늘 무슨 일이 있었나 → 2. 그 거래의 뿌리 → 3. 계획 대비 실행 → 4. 오늘의 판정 →
5. 잘한 것 (근거 있는 것만, 오늘 것만) → 6. 채점 · 내일 지킬 규칙 3개

**분량 기준 — 4쪽을 넘으면 누적 이야기가 섞여 들어간 것입니다.** 그 부분을 찾아 지우십시오.

## 계획 대비 실행 시트 상세

· 표1 아침에 정한 규칙 3개 — 규칙(원문) / 지켰나(O·X) / 위반 건수 / 판정 근거(어느 거래인지 인용).

· 표2 Jun 기재란 대조 — 아침에 적은 것 / 실제로 어땠나 / O·X

· 표3 계획 일치율 — 분자/분모를 명시하고 수식으로. Q-C 가 미기재면 분모가 왜곡되므로 그 사실을 산출 근거에 밝히십시오.
