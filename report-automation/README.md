# 보고서 자동화

이 폴더는 TradingManager의 수집·작성·PDF 제작·즉시 게시 모듈입니다. 웹과 같은 프로그램에 포함되지만 독립 프로세스로 실행됩니다. 개인 보고서와 계좌 기록, 인증정보, 예약은 배포하지 않습니다.

루트 설치 도구는 이 폴더의 `.env`에 **새로 설치한 로컬 웹의 키**만 기록합니다. DART·KIS·텔레그램 등을 사용하려면 본인의 키와 발송 대상을 여기에 추가하세요. SEC 자료를 수집하려면 `config.yaml`의 `sec_user_agent`에 본인 연락처를 입력하세요.

```sh
cd report-automation
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m playwright install chromium
```

보고서 생성은 `코덱스실행.py`를 통해 **이 컴퓨터 사용자의 ChatGPT 구독 로그인**을 사용합니다. 작성·분석과 요약 모델은 해당 모듈에서 설정합니다. 이용 가능한 Codex CLI와 본인 로그인이 필요하며 배포자의 세션이나 API 키는 포함하지 않습니다. API 키로 자동 대체하지 않습니다. 로컬 Ollama 챗봇과는 별도 선택 기능입니다.

`투자작업.sh`와 `제작엔진.sh`가 작성 작업을 실행합니다. 산출물을 자체 점검해 인계 상태를 `게시대기`로 저장하면 `자동검토.py --파일 <인계파일명> --완성 --한번`이 완성본을 즉시 게시합니다. 별도 최종 승인 모델이나 자동 수정 왕복은 없습니다. 실패한 동일 입력은 변경 또는 명시적 재시도 전까지 반복하지 않습니다.

자동 생성·텔레그램 발송 예약은 기본 설치에 등록하지 않습니다. 본인 설정 후 `작업표.txt`를 편집하고 `예약설치하기.command`를 실행하세요. 완성본 게시 감시기는 `bash 도구/자동검토_예약설치.sh`로 별도 설치합니다. 설치만으로 외부 AI 사용이나 메시지 발송이 시작되지 않습니다.

`지시문/`, `skills/`는 보고서 작성 기준이며, 실제 조사 자료와 이용자의 기록은 각 설치에서 별도로 준비합니다.
