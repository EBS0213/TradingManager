# 보고서 자동화

이 폴더는 TradingManager의 수집·작성·PDF 제작·즉시 게시 모듈입니다. 웹과 같은 프로그램에 포함되지만 독립 프로세스로 실행됩니다. 기본 예약 코드는 함께 배포하며, 개인 보고서·계좌 기록·인증정보·사용자 설정은 배포하지 않습니다.

루트 설치 도구는 이 폴더의 `.env`에 **새로 설치한 로컬 웹의 키**만 기록합니다. DART·KIS·텔레그램 등을 사용하려면 본인의 키와 발송 대상을 여기에 추가하세요. SEC 자료를 수집하려면 `config.yaml`의 `sec_user_agent`에 본인 연락처를 입력하세요.

```sh
cd report-automation
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m playwright install chromium
```

프로그램의 **설정 → 내 AI로 자동화 이어받기**에서 Codex 또는 Claude Code를 선택합니다. 선택한 도구 설치와 본인 계정 로그인이 필요합니다. 버튼을 누르면 AI에 이 설치의 경로·작업 절차·설정 상태를 전달하고, 인계 응답이 확인된 뒤 예약을 시작합니다. 배포자의 세션이나 API 키는 포함하지 않으며 API 키로 자동 대체하지 않습니다. 로컬 Ollama 챗봇과는 별도 기능입니다.

`투자작업.sh`와 `제작엔진.sh`가 작성 작업을 실행합니다. 산출물을 자체 점검해 인계 상태를 `게시대기`로 저장하면 `자동검토.py --파일 <인계파일명> --완성 --한번`이 완성본을 즉시 게시합니다. 별도 최종 승인 모델이나 자동 수정 왕복은 없습니다. 실패한 동일 입력은 변경 또는 명시적 재시도 전까지 반복하지 않습니다.

설치기는 보고서 Python 환경·PDF 생성 브라우저와 예약 실행기를 준비합니다. Mac은 사용자 로그인 후 백그라운드에서, Windows는 프로그램이 켜진 동안 실행됩니다. Windows 작성 스크립트에는 Git for Windows의 Bash가 필요합니다. 인계 전에는 예약 작업을 실행하지 않습니다.

기본 예약은 한국시간 평일 06:30 리포트 수집, 07:00 시황 작성, 08:30 컨콜 수집·작성, 16:30 기업 보고서 작성입니다. 완성본 게시기는 60초마다 확인합니다. 놓친 회차는 최근 평일 한 회차만 보충하며 같은 회차를 중복 실행하지 않습니다. 실패는 화면의 작업 상태와 `logs/report-*.log`에 남기고 다음 회차까지 반복하지 않습니다. 재인계는 AI 연결을 다시 확인하며 완료된 작업 이력을 지우지 않습니다.

SEC 연락처는 설정 화면에서 입력해 `data/report-automation/config.json`에 비공개로 저장합니다. 없으면 컨콜 작업만 설정 대기 상태가 됩니다. DART 등 선택 수집 키는 각 사용자의 `.env`로 관리합니다. 예약 중지는 진행 중인 작업을 완료한 뒤 새 작업을 멈춥니다. 이 예약 경로는 로컬 게시만 수행하며 텔레그램·이메일 발송은 활성화하지 않습니다.

이전 `예약설치하기.command` 예약과 새 실행기를 동시에 사용하면 중복될 수 있습니다. 기존 수동 예약을 사용하던 설치는 해당 예약을 먼저 정리하고 전환하세요. 다른 AI용 인계문 복사는 로컬 파일에 접근할 수 있는 AI에 전달하는 보조 기능이며, 웹 채팅만으로 이 컴퓨터의 예약이 실행되지는 않습니다.

`지시문/`, `skills/`는 보고서 작성 기준이며, 실제 조사 자료와 이용자의 기록은 각 설치에서 별도로 준비합니다.
