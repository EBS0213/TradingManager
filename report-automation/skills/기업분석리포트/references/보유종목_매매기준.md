# 보유 종목일 때 붙이는 매매 기준 절

`watchlist.csv` 의 구분이 '보유'인 종목에만 붙인다. 보고서 맨 뒤, 리스크 절 다음이다.

가치 분석과 매매 기준은 **다른 언어**다. 가치 포지션의 손절 근거는 근거(수주잔고·대손·증설)이고,
추세 포지션의 손절 근거는 가격이다. 이 둘을 한 계좌에서 섞으면 둘 다 망가진다.
그래서 이 절은 앞 절들과 분리해서 쓰고, 서두에 그 사실을 명시한다.

## 1. 변동성 실측이 먼저다

데이터팩의 `변동성` 표를 쓴다. 일간 변동 평균이 5%면 표준 손절폭 7~8%는 **정상 변동에도 체결된다.**

- 일간 변동 평균 × 2.5 를 손절폭 하한으로 본다 (8~20% 사이)
- 손절은 **종가 기준**으로 적용한다. 장중 꼬리에 털리지 않기 위해서다

## 2. 트렌드 템플릿 판정

데이터팩의 `추세 판정` 표를 그대로 옮기고, 미충족 조건이 **언제 회복될 수 있는지**를 적는다.
이동평균 정렬은 시간이 필요하다 — "골든크로스 복구는 빨라야 N분기" 식으로 시점을 계산한다.

불통과 상태면 **추가 매수(피라미딩) 대상이 아니다.** 이건 예외 없이 명시한다.

## 3. R배수 가격 레벨 표

1R = 매수단가 − 초기 손절선. 모든 가격을 R로 환산하면 판단이 단순해진다.

| 구간 | 가격 | R배수 | 성격 |
|---|---|---|---|
| 저항③ | | | 52주 최고(장중) |
| 저항② | | | 52주 최고(종가) · 적정가 밴드 하단과 겹치는 지점 |
| 저항① | | | 최근 고가 |
| 현재 | | | |
| 지지① | | 0R | 매수단가 · 본전 손절선 후보 |
| 지지② | | | 최근 갭 하단 |
| 지지③ | | −1.0R | 초기 손절선 |
| 지지④ | | | 추세 붕괴선 |

**적정가 밴드와 저항선이 겹치는 지점**을 반드시 찾아 표시한다. 가치와 추세가 같은 곳을 가리키면
그게 가장 강한 익절 후보다.

## 4. 포지션 사이징

계좌 리스크 2% 기준으로 손절폭별 최대 비중을 계산한다.

`최대 비중(%) = 계좌리스크(%) ÷ 손절폭(%)`

- 손절폭 8% → 25% / 15% → 13% / 20% → 10%

현재 비중이 이보다 크면 **손절선을 내리는 게 아니라 비중을 줄이는 것이 먼저다.** 이 문장을 반드시 넣는다.

## 5. 가치와 추세가 충돌할 때

- 가치는 사라는데 추세가 아니라면 → 비중을 줄이고 기다린다. 추세 조건 충족을 기다릴 시간은 있다.
- 추세는 좋은데 가치가 비싸다면 → 손절선을 올리며 따라간다. 대신 목표가에 도달하면 기계적으로 판다.
- **둘 다 아니면 나온다.** 보유 이유가 "이미 샀으니까"면 그건 이유가 아니다.
